# 定時休眠畫面規格

狀態：設計及運作時段已確認，留待下一階段實作。現時韌體不作更改。

## 正常運作時段

- 每日 02:30–04:00 正常運作。
- 每日 06:00–09:00 正常運作。
- 其餘時間進入休眠。
- 04:00 進入休眠後，畫面顯示下一次啟動時間「06:00 恢復」。
- 09:00 進入休眠後，畫面顯示下一次啟動時間「02:30 恢復」。

邊界規則：02:30 及 06:00 準時喚醒；04:00 及 09:00 準時進入休眠。

## 畫面

- 白色背景，大量留白。
- 右上角保留電池圖示及休眠前最後讀取的電量百分比。
- 畫面中央顯示細小月亮圖示及「休息中」。
- 下一行顯示下一次自動啟動時間，例如「06:00 恢復」。
- 不顯示即時時鐘、日期、巴士 ETA 或天氣，以免深度休眠期間畫面資料看似仍在更新。
- 提示區不超過畫面高度約 20%，字體保持低調但可辨認。

## 預定行為

1. 到達休眠時間前，讀取最後一次電量並畫出休眠畫面。
2. 關閉 Wi-Fi。
3. 設定 ESP32 定時喚醒時間。
4. 進入 deep sleep。
5. 到達下一個正常運作時段後喚醒，重新連線、更新資料並回復正常 dashboard。

## 實作前測試

先做短時間 deep-sleep 實機測試，確認 RLCD 在顯示控制器及 ESP32 休眠期間能否穩定保留畫面。如不能保留，改用 light sleep 或顯示控制器可支援的最低功耗模式。
